# Batch 3 — Environment Objects (`B3_environment`)

Tạo 1 ảnh sheet rồi thả vào `assets/inbox/B3_environment.png`.

```text
Create a 2.5D isometric game environment asset sheet (5 objects) on a solid flat pure white background with wide empty spacing between each object, no overlapping, no ground plane connecting them, no text or labels.

Strict 2.5D Isometric Camera & Style:
- True 2.5D isometric game projection (standard 2:1 isometric dimetric camera angle, elevated ~30 degrees, 45-degree diagonal orientation showing top and two front-isometric faces for solid structures).
- Gameplay-first low detail: clean readable silhouettes, soft rounded shapes, minimal surface noise.
- Soft painterly cel shading, top-left 45-degree warm daylight, crisp dark indigo-slate ink outline (#1E293B).
- Unified color palette:
  - Soft Jade Green (#6BBF9B) & Deep Jade Moss (#4E9A7A)
  - Warm Cream (#F5EFE0) & Carved Stone (#E4D8BE)
  - Muted Crimson (#C95B5B)
  - Deep Indigo-Slate (#1E293B)

Layout (5 separate isometric objects in a clean 3x2 grid):
1. Top-left (Tree Green): 2.5D isometric stylized round canopy tree, soft jade green foliage (#6BBF9B, #4E9A7A shadow), simple warm stone-brown trunk (#E4D8BE) with small base footprint.
2. Top-center (Tree Peach): 2.5D isometric stylized round peach blossom tree, warm cream blossoms (#F5EFE0) lightly tinted with muted crimson pink (#C95B5B), dark trunk (#1E293B).
3. Top-right (Mossy Rock): 2.5D isometric rounded boulder, carved stone (#E4D8BE, #F5EFE0 highlights) with a soft jade moss cap (#6BBF9B) on top.
4. Bottom-left (Cliff Edge): 2.5D isometric floating island corner/edge block, carved stone vertical cliff faces (#E4D8BE) angled along 2:1 isometric axes with a soft jade grass rim (#6BBF9B) on top.
5. Bottom-right (Stone Bridge): 2.5D isometric walkable stone bridge aligned to a 45-degree isometric diagonal, warm cream (#F5EFE0) and carved stone (#E4D8BE) deck planks with low rounded side rails.

Negative constraints: No flat 2D side-view, no pure 90-degree top-down view, no photorealism, no cast shadows on background, no overlapping objects, no text.
```
