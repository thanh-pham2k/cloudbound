# Batch Prompts — Cloudbound Base Assets (`assets/prompt/`)

Bộ prompt độc lập để tạo ảnh **2.5D Isometric** theo batch. Bạn chỉ cần tạo ảnh từ các prompt dưới đây rồi thả file ảnh vào `assets/inbox/`, mình sẽ tự xử lý (tách nền, cắt, chuẩn hóa kích thước, lưu `assets/references/` và `base.png` vào từng folder).

## Danh sách file thả vào `assets/inbox/`
1. **[B1_characters.md](B1_characters.md)** → `assets/inbox/B1_characters.png`
2. **[B2_tiles.md](B2_tiles.md)** → `assets/inbox/B2_tile_grass.png` và `assets/inbox/B2_tile_stone.png`
3. **[B3_environment.md](B3_environment.md)** → `assets/inbox/B3_environment.png`
4. **[B4_props.md](B4_props.md)** → `assets/inbox/B4_props.png`
