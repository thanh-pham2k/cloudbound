# Asset archive

New source sheets go in `assets/inbox/`. Move validated source sheets here after extraction and update the corresponding extractor and manifest.

Survivor originals are grouped under `adapted/survivor/`.

- `base/` contains 15 sheets for the original Survivor build.
- `polish/` contains 14 sheets for the animation and VFX pass.
- `enemies/` contains 27 sheets for the enemy roster.
- `summon/` contains 10 sheets for the commander shop, shared monkey poses, equipment and effects.
- `combat/` contains 10 sheets for the Monkey Army combat animations and modular combat VFX.
- `vfx/` contains 7 sheets for the advanced combat VFX pack.

Godot uses the extracted assets in `assets/survivor/`. The previous exploration sprite set remains recoverable from Git history.
