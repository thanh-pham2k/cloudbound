# Reference Library (`assets/references/`)

Thư mục này chứa các **Golden Reference Images** dùng làm chuẩn thị giác cho từng nhóm asset, tuân theo `assets/visual_bible.yaml`.

## Các nhóm chuẩn
- `environment.png` — Terrain, đảo mây, cây, đá, đường lát đá, ánh sáng và độ tương phản nền.
- `characters.png` — Tỷ lệ chibi (~1:2 đến 1:2.5), khuôn mặt, trang phục, nét viền và góc nhìn 3/4 top-down.
- `props.png` — Vật thể tương tác (rương, đèn lồng, trụ rune, cổng trời), kích thước tương đối và độ chi tiết.
- `vfx.png` — Hiệu ứng chiến đấu, telegraph cảnh báo, rune phát sáng.

## Quy tắc
1. Mỗi nhóm dùng một ảnh reference chính để giữ nhất quán scale và góc nhìn.
2. Không tự ý thay đổi Golden Reference khi chưa nâng `bible_version` trong `assets/visual_bible.yaml`.
