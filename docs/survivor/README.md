# Hoa Quả Sơn — Monkey Army Defense

Open `project.godot` in Godot 4.7.2, press **F5**, and choose **Start Game**. Use the bottom panel to summon Staff, Archer, Mage, Tank and Healer monkeys with Gold while combat runs. The army can field up to eight monkeys and responds to enemies across three lanes while Sun Wukong commands from the rear center. **Train army** upgrades current and future recruits. **Esc** pauses or resumes the match.
